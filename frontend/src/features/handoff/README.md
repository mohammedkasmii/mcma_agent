# handoff

Reserved for the human-review handoff: the moment the agent stops and an
employee takes over in SinAuto, then confirms completion or reports a
problem.

Empty in STEP 1. The application never performs final validation, dossier
closure, the final Enregistrer action, GED uploads or devis validation, and
the interface must never imply that it did.

This file exists so the directory is tracked by git, which does not record
empty directories.
